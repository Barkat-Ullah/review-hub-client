# ReviewHub

![ReviewHub Thumbnail](https://i.ibb.co.com/nNntzRxB/Review-Hub-04-16-2026-10-30-AM.png)

**ReviewHub** is a modern **Product Review Portal** where users can share honest reviews, interact with the community, and access premium content. Admins can efficiently moderate reviews and manage the platform.

## Live Demo
Check out the live version:
[ReviewHub - Product Review Portal](https://review-hub-ruby.vercel.app)

---

## ✨ Key Features

### User Features
- **Authentication**: Secure registration and login with JWT session management
- **Write Reviews**: Create, edit, and delete reviews with title, description, rating (1-5 stars), category, purchase source, and images
- **Categorization**: Organize reviews into categories like Gadgets, Clothing, Books, Electronics, etc.
- **Engagement**: Upvote/downvote reviews, remove votes, comment, and reply on reviews
- **Premium Reviews**: Pay a one-time fee (via **SSLCommerz** or **ShurjoPay**) to unlock full premium review content
- **Search & Filter**: Powerful search by keyword and filters by category, rating, date, and popularity
- **Responsive Design**: Beautiful, fully responsive UI for mobile, tablet, and desktop
- **Profile Management**: View payment history and manage account settings

### Admin Features
- **Content Moderation**: Approve, reject, or unpublish user reviews and comments
- **Premium Review Management**: Create and manage premium reviews with pricing
- **Dashboard**: Comprehensive overview and management of all reviews, comments, and payments

---

## 🛠️ Technology Stack

- **Frontend**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Authentication**: JWT
- **Payment**: SSLCommerz / ShurjoPay
- **Deployment**: Vercel
